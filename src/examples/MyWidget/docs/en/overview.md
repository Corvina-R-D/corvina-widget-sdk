# My Widget

An example of a widget with its own help: these pages are `docs/<locale>/<page>.md` next to the widget,
compiled into the package when it is built.

![My Widget](../../../../resources/images/corvina-widget1.png)

The widget shows a title, its **Message** and the value of **Linkable Prop**. See
[the properties](properties.md) for what each one does, or [Linkable Prop](properties.md#linkable-prop)
for the one that takes a datalink.
