# Il mio widget

Un esempio di widget con il suo help: queste pagine sono `docs/<locale>/<pagina>.md` accanto al widget,
compilate nel pacchetto quando lo si costruisce.

![Il mio widget](../../../../resources/images/corvina-widget1.png)

Il widget mostra un titolo, il suo **Message** e il valore di **Linkable Prop**. Vedi
[le proprietà](properties.md) per cosa fa ciascuna, o [Linkable Prop](properties.md#linkable-prop)
per quella che accetta un datalink.
